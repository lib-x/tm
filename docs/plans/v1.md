# TMP v1 实施与验收

1. 审阅旧 CBOR/WebSocket 方案，记录阻断项；新 wire 使用独立标识 `tmp.pb.v1`，不冒用 `tunnel.tmp1`。
2. 冻结 Protobuf schema、可靠有序 Transport 合同、握手与流状态机、资源上限和应用 profiles，交独立 agent 评审。
3. 并行实现 Rust、Go、Node SDK：生成模型、增量 framing、会话状态机、stream transport 适配、示例。
4. 运行 SDK 单测、公共 golden vectors、三语言循环互通、格式/静态检查；修复独立评审问题后再次评审。

完成标准：SSH/WS/QUIC 不出现在 core schema；不依赖某个 socket 库；支持双端开流/确认、显式消费信用、FIN/RESET/GOAWAY；无内建透明重放；三套 SDK 能交换同一 wire transcript。发布范围是可嵌入的协议 SDK，不包括 relay 服务、桌面编码器或 herdr 后端。
